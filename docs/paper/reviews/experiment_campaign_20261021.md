## 测评条件

基准为3 UAV、100 GU、22个需求中心、250槽、总平均到达率40 Mbit/s。固定策略直接迁移到各条件，每次只改变指定因素。

| 条件 | 设置 |
| --- | --- |
| 名义点 | 原始冻结配置。 |
| 负载 | 60和80 Mbit/s。 |
| 接入带宽 | 基准的0.5、0.75、1.5、2倍，保持回传和CPU不变。 |
| 回传带宽 | 基准的0.5、0.75、1.5、2倍，保持接入和CPU不变。 |
| 卫星CPU | 基准的0.5、0.75、1.5、2倍，保持接入和回传不变。 |
| 热点强度 | 倍率1和8，保持总平均到达量及其他设置不变。 |
| 热点持续时间 | 平均持续5和50槽，保持其他设置不变。 |
| 长时域 | 1000槽，总平均到达率分别40和60 Mbit/s。 |

共21个条件。每个策略每个条件使用两个测试seed区间，每区间64个episode，共128个episode；32个并行环境。测试seed base为20421000和20422000。GPU0验收使用20420000区间；训练恢复与内外部测评一致性验收沿用1910000区间。

名义点另外测三个STARS的final策略。完整测评队列共216个任务、13824个episode，另计验收任务。

## 首批训练对照

从原STARS有效配置派生，只修改训练seed、structured_actor_backbone和critic_value_mode。两个网络模式均改为flat_mlp。环境、动作约束、安全执行、奖励、阶段训练、优化器、验证及停止规则沿用冻结协议。

该对照保留现有顺序执行与阶段训练，名称为FlatActorCritic结构学习对照。它检验整体网络表示的作用；独立MAPPO和共享时隙价值消融另行适配。

每个种子先通过8环境训练与恢复、内部和外部测评一致性、64环境训练及各动作头实际更新检查，再进入正式训练。正式训练使用64环境、每次250槽，更新上限700，保留实际停止原因及完成更新数，每25次更新保存checkpoint。

训练后分别测selected和final策略。历史协议的1980000与1981000区间各32个episode，保留为历史可比测评；新一轮正式比较使用独立的20421000与20422000区间。

## 指标

| 指标 | 口径 |
| --- | --- |
| 平均总队列 | 所有GU、UAV、卫星的逐槽post-service队列总量取均值，以Mbit报告。 |
| 工作量完成比例 | 累计卫星处理量除以累计实际到达量。 |
| 工作量丢弃比例 | 累计三级溢出丢弃量除以累计实际到达量。 |
| 终端残余比例 | 最后观测到的post-service总队列除以累计实际到达量。 |
| 原目标平均成本 | 原始W加Phi逐槽累计后除以实际观测槽数。 |
| 可靠性 | 碰撞、提前终止、实际观测长度、是否完成设定时域。 |
| 学习结果 | 原始验证曲线、selected与final结果、实际更新数、各阶段价值拟合与actor更新诊断。 |

逐episode验证完成比例、丢弃比例与终端残余比例之和，允许1e-4的数值误差。提前终止保留在结果中并显式标记；其指标对应实际观测时域。队列与服务量比值仅作代理指标。

## 运行证据

每次实验固定源码commit、源码归档hash、配置hash、checkpoint hash、episode seed和完整命令。原运行目录保持原样，新结果写入本轮独立目录。

训练种子独立汇总；同一策略的多个episode不作为独立训练重复。新测评集用于报告，不参与checkpoint选择和调参。任一验收或守恒检查失败时，停止对应队列并保留失败现场。
